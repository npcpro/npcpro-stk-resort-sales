# STK Resort — Presentation website

เว็บนำเสนอภาษาไทยแบบ static ใช้ HTML, CSS และ JavaScript เปิด `index.html` ดูได้โดยไม่ต้องติดตั้ง dependency ใช้ภาพและวิดีโอที่ได้รับจาก `source/` เท่านั้น โดยเตรียมภาพ WebP สำหรับเว็บใน `assets/`

## GitHub Pages

เผยแพร่ผ่าน GitHub Pages แบบ Deploy from a branch: branch `main`, โฟลเดอร์ `/ (root)` ไม่ต้องติดตั้ง dependencies หรือใช้ custom workflow ไฟล์ `.nojekyll` เปิดให้เสิร์ฟเว็บ static โดยตรง

GitHub แจ้งว่าแพ็กเกจปัจจุบันยังไม่รองรับ Pages จาก repository Private การเปิดเว็บต้องใช้ repository Public หรือแพ็กเกจที่รองรับ

URL ที่คาดว่าจะได้เมื่อเปิด Pages และ deploy สำเร็จ: https://npcpro.github.io/npcpro-stk-resort-sales/

## ข้อมูลที่ใช้

- ราคาเสนอขาย 280 ล้านบาท: ข้อมูลจากผู้ใช้
- เนื้อที่ 19 ไร่ 87 ตารางวา และจำนวน 215 ห้อง: ภาพประกาศ `source/main.jpg` ต้องตรวจเอกสารจริงก่อนซื้อขาย
- ให้บริการรายเดือน ผู้พักเป็นนักศึกษาและคนทำงาน ระบบน้ำไฟและเน็ตใช้งานอยู่: ข้อมูลจากผู้ใช้
- ผู้ประสานงาน: Bright โทร 064-490-8881 ตามข้อมูลที่ผู้ใช้ระบุ ไม่แสดงภาพประกาศที่มีเบอร์เดิมบนเว็บ
- ไม่แสดงอัตราเข้าพัก 85% เพราะยังเป็นค่าประมาณ ไม่รับรองผลตอบแทนหรือสิทธิสร้างอาคารเพิ่ม
- แผนที่ฝังและลิงก์นำทางใช้พิกัด 20.0444541, 99.8797407 จากลิงก์ Google Maps ที่ผู้ใช้ส่งให้
